# project create の失敗復旧

プロジェクト作成がディレクトリ作成、メタデータ書き込み、DB ファイル作成の途中で失敗した場合、その呼び出しで新規作成したプロジェクト領域を削除します。新規作成した親ディレクトリは空の場合だけ削除します。既存プロジェクト・ファイル・未完成プロジェクトを自動削除することはありません。

障害を解消した後、同じ名前の `lorairo-cli project create NAME` を再実行できます。正常作成済みの名前を再指定した場合の `ALREADY_EXISTS` は従来どおりです。

cleanup 自体が失敗した場合、`--json` の stdout 最終行（`kind=error`, `code=INTERNAL_ERROR`, 終了コード 1）の `details` に以下を出力します。

- `original_error`: 作成処理の元エラー。API 例外の `__cause__` にも保持します。
- `cleanup_errors`: cleanup に失敗したパスとエラーの一覧。
- `residual_paths`: cleanup を完了できなかったプロジェクト領域・親ディレクトリ。
- `recovery`: 残留内容の確認、ファイルシステム障害の解消、未完成プロジェクトだけの除去、create 再実行の案内。

残留する親ディレクトリには別のファイルが入っていることがあります。残留パスをまとめて再帰削除せず、内容を確認してください。メタデータまで作成された未完成プロジェクトは同名作成を拒否するため、内容確認後の明示的な `project delete NAME --force` または未完成ディレクトリの除去で復旧できます。
