# ADR 0020: CLI Message Language Policy

## Context

`lorairo-cli` のユーザー向けメッセージにおいて、日本語と英語が混在していた(ISSUE #203)。コマンドごとに言語が異なっており、出力に一貫性がなかった。

## Decision

**詳細な説明を含む ERROR および WARNING メッセージは、英日併記とする。**

- 英語を第 1 行、日本語を第 2 行に表示する。
- プログレスバーラベル、テーブルヘッダー、省略表示(`... and N more`)、ヒント例などの短い要素は英語のみとする。
- `loguru logger` による内部ログ(`logger.warning/debug/error`)は日本語のままとする。

## Rationale

- **英語のみへの統一**は変更コストが低いものの、主要ユーザーである日本語話者への配慮に欠ける。
- **日本語のみへの統一**は CLI ツールの一般的な慣例から外れるうえ、変更コストが大きい。
- **英日併記**であれば、日本語話者・英語話者の双方に分かりやすいメッセージを提供しつつ、最小限の変更で一貫性を確保できる。
- `gettext` などの本格的な i18n 対応は、現フェーズでは過剰設計(YAGNI)である。

## Consequences

- ERROR および WARNING メッセージが 2 行になり出力はやや長くなるが、実用上は許容範囲である。
- 新たにユーザー向けメッセージを追加する際は、本 ADR の方針に従う必要がある。
- テストでメッセージ内容を検証する場合は、安定性を確保するため英語部分を使用する。
