# ADR 0007: Batch Tag Annotation UX

## Context

バッチタグアノテーションの UI には、次の 3 つの課題があった。

1. ステージング一覧(左 50%)とアノテーション操作部(右 50%)が左右に分断されており、利用者が視線を往復させる必要があった。
2. ステージング画像数が静的テキスト表示のみであり、対象が 0 件でも実行ボタンが有効なままだった。
3. アノテーション実行中の進捗フィードバックが弱く、処理中の画像やモデルが UI 上で確認できなかった。

## Decision

次の UI 改善を実施する。

- ステージング画像数を動的カウントで表示する(例: `"◎ ステージング: 25枚 / 500枚"`)。
- ステージング対象が 0 件のときは実行ボタンを無効化する。
- `WorkerProgress` Signal を UI に接続し、現在処理中の画像とモデルを表示する。
- ステージング一覧とアノテーション操作部を視覚的に統合するようレイアウトを改善する。

## Rationale

対象が 0 件の状態でアノテーションを実行してしまう誤操作を UX の改善によって防止できる。また、`WorkerProgress` Signal はすでに実装されているため、低いコストで進捗表示を接続できる。

## Consequences

- `labelAnnotationTarget` は静的テキストから動的更新される表示へ変更される。
- `btnAnnotationExecute` はステージング件数に応じて有効・無効が自動で切り替わる。
- ステージング件数の変更を UI へ反映するためのシグナル接続が必要になる。
