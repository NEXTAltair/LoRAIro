# ADR 0100: 登録日フィルタはスライダーを唯一の状態にし、暦日の境界を 1 箇所で決める

## Context

検索パネルの登録日(`Image.created_at`)フィルタには、範囲スライダー、サイドバーのヒストグラム、そして要望されているクイック選択の 3 つの UI がある。

従来のようにヒストグラムの選択をスライダーとは別の第 2 の条件として検索へ渡すと、次の問題が個別に発生した。

- 境界の丸め(小数秒の扱い)
- 保存形式の精度差(秒精度テキストとマイクロ秒付きテキストの文字列比較)
- 内部ビン境界の包含(`<=`)による重複
- 保存フィルタへの保存と復元における不整合

これらはいずれも、「どの UI がどの範囲を、どのような境界の意味で保持するか」が定まっていないことが原因である。あわせて、スライダーが秒単位(1 日あたり約 86,400 段階)だったため 1 日単位で選択できず、UTC とローカル時刻の変換処理も箇所ごとにばらついていた。

## Decision

### 1. 状態はスライダーに一本化する

登録日フィルタが保持する状態は、「登録日フィルタが有効かどうか」と「スライダーの暦日範囲(開始日・終了日とも含む)」の 2 つだけにする。

- クイック選択とヒストグラムはスライダーの値を書き換えるだけであり、独自の範囲状態を持たない。
- ヒストグラムの選択状態はファセット値に含めず、バーの強調表示もスライダーの範囲から導出する。

### 2. クイック選択は単一選択のチップにする

クイック選択には「すべて / 今日 / 昨日 / 7日 / 30日 / カスタム」の単一選択チップを用意する。

- 「すべて」を選ぶとフィルタは無効になる。
- スライダーは「カスタム」選択時のみ表示する。
- スライダーを手動で動かすか、ヒストグラムのバーを選ぶと自動的に「カスタム」へ切り替わる。
- 保存フィルタを復元する際は、保存された範囲から該当するプリセットを導出する。

### 3. 粒度はローカル時刻の暦日単位にする

スライダーの値は `date.toordinal()` を用い、1 目盛りを 1 日とする。「過去 N 日」は今日を含む直近 N 暦日として扱う。

### 4. 境界規則と時刻変換を 1 箇所へ集約する

境界の計算と時刻変換は、Qt 非依存の純粋関数モジュール `lorairo.domain.registration_date_range` に集約する。

- 検索の境界は「開始日 00:00:00 以上、終了日の翌日 00:00:00 未満」の半開区間とする。
- ローカル時刻からタイムゾーンなし(naive)の UTC への変換は、このモジュール内で 1 回だけ行う。
- ヒストグラムのビンも同じモジュールで暦日単位に生成し、検索と同じ条件式で件数を数える。表示時は逆変換で暦日に戻す。

### 5. DB 比較は保存形式の精度に依存させない

SQLite の datetime はタイムゾーンなしの UTC テキストであり、秒精度・マイクロ秒付き・`T` 区切りが混在し得る。これを安全に比較するため、保存値と境界の双方を同じ正規形テキスト(`YYYY-MM-DD HH:MM:SS.ffffff`、naive UTC、小数部 6 桁)へそろえて比較する。

- `julianday()` はミリ秒へ丸めるため使わない(`.999999` が翌日として判定されるのを防ぐ)。
- 境界値がタイムゾーン付き(aware)であれば、UTC に変換してから正規形へ整形する。

### 6. 対象列・公開契約・保存形式

- 絞り込み対象の列は `Image.created_at`(登録日)とする。
- 排他の終了境界は内部用の `end_date_exclusive` で渡し、CLI の公開契約(`start_date` / `end_date` は両端を含む)は変更しない。
- 保存フィルタにはスライダーの暦日を ISO 日付で保存する。旧形式(epoch 秒)を読み込む際はローカル暦日へ変換する。

## Rationale

- 状態を 1 つに統一すれば、保存・復元・クリア・積集合の個別規則が不要になり、画面表示と検索条件が常に一致する。
- 粒度を暦日単位にすれば、境界は常にローカル時刻の 00:00 となるため、ビン境界の小数秒や内部境界の包含問題が起こらない。
- ヒストグラム選択を第 2 の条件として残す案は、保存・クリア・積集合の規則が複雑化する。一方で、ヒストグラムを表示専用にする案は既存のバー選択機能を失うため採らない。

## Consequences

- ヒストグラムのバーを選ぶと、ビンの範囲がスライダーへ反映され、件数見積もりが更新される。他のファセットのような即時再検索は行わず、スライダー操作と同様に適用ボタンで検索を実行する。
- ヒストグラムのビンが暦日単位になるため、対象期間が短い場合はビン数が 20 未満になることがある。
- 「今日」などのクイック選択も保存時点の暦日として保存され、相対期間としては保存されない。
- 日付フィルタの対象列が `updated_at` から `created_at` へ変わるため、CLI の日付指定も登録日で絞り込む挙動になる。
