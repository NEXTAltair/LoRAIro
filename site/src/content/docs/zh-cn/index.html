LoRAIro 是一款桌面应用，可导入 LoRA 训练图片，使用 AI 生成标签、描述文本和评分，检查内容后导出数据集。它不负责执行模型训练。

首次使用

  1. 在 Windows 安装并启动图形界面。
  2. 导入图片，然后搜索并加入待处理区。
  3. 执行 AI 标注，在 Jobs 查看结果。
  4. 检查和修改标签，然后导出数据集。

建议先用少量图片完成整个流程。选择 WebAPI 后，图片将发送到外部服务，并可能产生费用。

本指南的范围

本使用指南提供日语、英语、繁体中文和简体中文。日语为原文，其他语言由 AI 辅助翻译。如果含义存在差异，请以日语为准，并在 GitHub 报告问题。

指南支持四种语言，并不表示应用界面支持四种语言，也不表示图片标签和描述文本会自动翻译。各功能的支持范围见对应章节。

开发者设计文档和 ADR 保留在仓库的 docs 中。本指南按照当前操作流程编写，不是旧版 Sphinx 自动生成的 API 列表。

保护数据

AI 标注和标签编辑会修改项目数据库。大量修改前请先备份，并区分仅用于导出的临时调整和数据库的永久修改。
