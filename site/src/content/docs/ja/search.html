検索結果と実行対象は別

GUIでタグなどを指定して画像を絞り、サムネイルを選択し、「選択をステージングへ」で処理対象に追加します。検索結果に表示されたことや、サムネイルを選択したことだけでは実行対象になりません。

ステージング集合はアノテーションとエクスポートで共用します。上限は500枚で、同じ画像は重複追加されません。実行直前に対象枚数と内容を確認してください。

ステージングの「クリア」は対象集合から外す操作で、画像をDBから削除する操作ではありません。

GUI検索

タグ検索には除外指定（-tag）も使えます。条件変更後は件数とサムネイルを確認し、目的の画像が含まれているかを確かめます。評価やモデル不足など、用途に合う条件も組み合わせます。

CLI検索

PowerShellでJSONを直接埋め込む際の引用符問題を避けるため、UTF-8のquery.jsonを作成します。

{"tags":["cat"],"excluded_tags":["dog"],"limit":100}

uv run --no-sync lorairo-cli --json images search -p "my-project" --query-file query.json
uv run --no-sync lorairo-cli images show 42 57 -p "my-project"

検索の既定値ではinclude_nsfwはfalseです。検索条件による除外と未登録を混同しないでください。大きな集合には件数ガードがあります。大量のIDを列挙する用途では、クエリーに"emit_ids":trueを明示します。

--jsonの標準出力はJSONLです。結果だけでなくメッセージ種別を持つ行があるため、出力全体をそのまま画像IDファイルとして使わないでください。CLI補足も参照してください。
