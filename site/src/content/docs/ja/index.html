LoRAIroは、LoRA学習用の画像を登録し、AIでタグ・キャプション・評価を付け、内容を確認してデータセットへ出力するデスクトップアプリです。学習そのものを実行するツールではありません。

初めて使うとき

  1. WindowsでインストールしてGUIを起動します。
  2. 画像を登録し、検索してステージングします。
  3. アノテーションを実行し、Jobsで結果を確認します。
  4. タグを確認・修正してから、データセットを出力します。

最初は少数の画像で一連の操作を試してください。WebAPIを選ぶと画像が外部に送信され、利用料金が発生する場合があります。

このガイドの範囲

利用者向けの手順は日本語・英語・繁体字・簡体字で提供します。日本語が原本で、他言語はAI支援翻訳です。意味の食い違いがあれば日本語を基準にし、GitHubで報告してください。

ガイドの4言語対応は、アプリ画面の4言語化や、画像タグ・キャプションの自動翻訳を意味しません。各機能の対応範囲は個別の章で説明します。

開発者向けの設計資料・ADRはリポジトリのdocsに残しています。旧Sphinxの自動生成API一覧ではなく、現行操作に沿った利用ガイドです。

データを守る

アノテーションやタグ編集はプロジェクトのデータベースを書き換えます。大きな変更の前にはバックアップを取り、出力用の一時変更とDBの恒久変更を区別してください。
